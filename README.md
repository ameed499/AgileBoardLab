## Features

- **Search books:** Students can search by title, author or subject. The system shows "No books found" when nothing matches.
- **View book availability:** Every book shows its status as Available or Issued. Issued books show the expected return date.
- **Reserve an available book:** A Reserve button is shown only for available books. A reservation is automatically cancelled after 24 hours and the book becomes available again.
- **Renew an issued book:** Students can renew an issued book. The return date moves forward by 7 days. Renewal is rejected if another student has reserved the book.
- **Return date reminder:** The system sends a reminder 2 days before the return date with the book title and the return date.
